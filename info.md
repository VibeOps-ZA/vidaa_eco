# VIDAA Eco

Local control of Hisense **VIDAA** TVs — power (with Wake-on-LAN), volume,
inputs, apps and every practical remote key as buttons — plus **automatic
power-off** when a TV is left on idle (home screen, or an input with no signal).

- Activity and Auto-off status sensors
- Remote, app and input buttons for dashboards and scenes
- Ready-made remote-style dashboard (see the README)

Requires the VIDAA client certificate in `config/certs/` — see the README.
